# The College Edit — MKTG:4400 project

Fictional, AI-generated site for a University of Iowa class project. Five pages are included.

## Publish on GitHub Pages

1. Create a **public** GitHub repository called `college-style-guide`.
2. Upload the contents of this folder to the repository root (index.html should be at the root).
3. In GitHub, open **Settings → Pages**. Choose **Deploy from a branch**, `main`, `/ (root)`, and Save.
4. Your website should then become available at `https://YOUR-USERNAME.github.io/college-style-guide/` (substitute your actual GitHub username).
5. Replace `YOUR-USERNAME` in `robots.txt` and `sitemap.xml` with your GitHub username, commit, and verify the two URLs live.
6. In Google Search Console add the site using **URL prefix**, verify ownership as directed, and submit `sitemap.xml` in the Sitemaps menu. Capture baseline screenshots and record date.
7. Open the site in a private window and on a phone-size screen to test all links and notices.

**Important:** GitHub commits made on different dates cannot be backdated; make real changes with meaningful notes across separate days. If there aren't four yet, don't claim there are.

**Suggested AI disclosure:** ChatGPT generated the fictional website content, page layouts, HTML/CSS, and initial SEO copy; I reviewed and published the site.
